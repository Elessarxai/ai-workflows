# ai-workflows

Practical AI workflows and agents I use and write about on X as [@elessarqq](https://x.com/elessarqq). Each folder is one workflow: copy-paste prompts, a one-time setup and the article it comes from.

| Workflow | What it does | Article |
|---|---|---|
| [ipo-filing-reader](ipo-filing-reader/) | One prompt that reads an IPO filing (S-1) like a skeptical buyer and lists every deal where someone gets a better price than you, with quotes and page numbers | [Amazon gets new Anthropic shares at $2.09](https://x.com/elessarqq/status/2120494499831119942) |
| [trading-desk](trading-desk/) | 10 jobs Claude does around a trade: market rules, token contracts, unlock calendars, audits, a morning brief, a red team, a trade autopsy, a rule checker, position sizing and backtests | [I Want Claude to Do All the Dirty Work of Trading](https://x.com/elessarqq/status/2110353431927869607) |
| [video-remake](video-remake/) | 5 steps to rebuild a viral video format with your own content: break the reference down, map it to your post, build one HTML page, check stills, render to MP4 and GIF | [How to Remake Any Viral Video Format With Claude Code](https://x.com/elessarqq/status/2117300649469571076) |

New workflows land here with new articles.

## How to use

1. Open a folder and read its README.
2. Do the one-time setup it describes.
3. Copy a prompt into Claude (or Claude Code, when the folder says so), attach what it asks for, and read the result.

## Two rules

- Ask where every number came from. The prompts here ask Claude for sources for that reason.
- Never paste seed phrases, private keys or API keys into any AI chat.

Nothing here is financial advice.
