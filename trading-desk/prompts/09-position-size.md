# Job 9: A position-size calculator

**When:** Tools you build once  
**You need:** Nothing. Ask once and keep the page.

## Prompt

```text
Build me a position size calculator as one page I can keep using. Pre-fill account size and risk % from my DESK PROFILE if it's there.

Inputs: account size, % risk, entry, stop, optional take-profit, long or short.
Outputs: position size in units and money, loss if the stop hits, risk-to-reward if a take-profit is set, leverage needed if the position is bigger than the account.
Warnings: red warning above 2% risk, and a warning if the stop is on the wrong side of the entry.

Dark theme, works on mobile, and show the formula under the result so I can check the maths.
```

## Notes

No more maths in your head at 3 a.m. when you're tired and emotional.
